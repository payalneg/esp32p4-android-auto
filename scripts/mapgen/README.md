# mapgen — генератор данных оффлайн-карты

Готовит данные для экрана оффлайн-карты прошивки (`main/map_screen.c`,
`UI_MODE_MAP`, жест тремя пальцами при выборе «Offline Maps» в настройках):

- **векторные тайлы VTL2** `vtiles/{z}/{x}/{y}.vtile` — слои
  вода/зелень/дороги/ж-д/здания/подписи, полигоны пре-триангулированы,
  парсер на устройстве — `main/map_vtile.c`;
- **`vtiles/route_graph.bin`** (формат RGF2) — граф веломаршрутов для A*
  (`main/map_router.c`);
- **`vtiles/search_index.tsv`** — плоский поисковый индекс адресов и POI
  (`main/map_search.c`).

Источники истины по форматам: `vtile_format.py` (VTL2) и `graph_format.py`
(RGF2) — C-парсеры прошивки написаны по ним.

## Зависимости

```sh
pip install osmium          # pyosmium (для --build)
# для десктопного просмотрщика: pillow (+ tkinter из системного python)
```

## Использование

Регион и bbox настраиваются в `config.py` (сейчас — Краков,
выгрузка Geofabrik malopolskie).

```sh
cd scripts/mapgen
python main.py --download-pbf   # скачать .osm.pbf региона (~200 МБ)
python main.py --build          # собрать vtiles/ + граф + поисковый индекс
python main.py                  # десктопный просмотрщик собранных данных
```

Сборка Малопольши даёт ~106 МБ: тайлы z8–z14 (~88 МБ), граф ~18 МБ,
индекс ~7 МБ.

## На устройство

Каталог `vtiles/` целиком копируется в корень microSD:

```
/sdcard/vtiles/{z}/{x}/{y}.vtile
/sdcard/vtiles/route_graph.bin
/sdcard/vtiles/search_index.tsv
```

Прошивка монтирует SD лениво при первом входе на экран карты; без данных
экран покажет подсказку. Граф маршрутов грузится в PSRAM (~18 МБ) только
при первом запросе маршрута — для регионов сильно больше Малопольши
может не хватить памяти (см. комментарий в `main/map_router.h`).

## В приложение на телефоне

Навигатору в `flutter-application` нужны только два файла из `vtiles/` —
граф и поисковый индекс; растровые тайлы он берёт с osm.org и кэширует сам.
Раздать их проще всего прямо отсюда:

```sh
cd scripts/mapgen/vtiles && python3 -m http.server 8000
```

Дальше в приложении: Навигатор → шестерёнка → Данные карты → адрес
`http://<ip-этой-машины>:8000/` → «Скачать». Телефон и компьютер должны быть
в одной сети. Файлы можно и просто скинуть на телефон и выбрать кнопкой
«Импортировать».

Формат читает `flutter-application/lib/nav/rgf2.dart`; порядок классов дорог
в `profiles.py` — это байт в каждом ребре, и он закреплён тестом
`test/nav/way_classes_test.dart`, который парсит этот же файл. Менять порядок
нельзя, только дописывать в конец.

Прошивка головного устройства (`main/map_router.c`) пока читает **RGF1** —
старый формат со временем проезда вместо класса дороги. До её обновления
один и тот же граф в дисплей и в приложение не подойдёт; магия файла
поменялась специально, чтобы старый парсер падал явно, а не читал мусор.
